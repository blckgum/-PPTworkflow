# 布局参考

所有页面都必须填写 `layout` 和 `title`。除封面与分隔型布局外，通常按标题、副标题、核心句、正文区域的顺序排版。页眉、来源页脚、建议时长由引擎统一处理。

普通布局可使用共用图片字段：有图自动分配侧图位置，没有图片则正文使用全宽。每页最多三张侧图，建议一张；图注写明时间、地点、来源，概念图明确注明示意。

| layout | 必填专用字段 | 可选专用字段 | 布局与建议 |
|---|---|---|---|
| cover | image | subtitle2、question | 一张全出血图；大标题、两级副标题、开场问题、核心句 |
| statement | 无 | 无 | 单句大字与大量留白；subtitle、key 支持共用字段 |
| points | bullet | body | 核心句＋要点；建议 3–5 条 |
| blocks | head 与 body | 无 | 小标题＋正文成对排列，标题加粗；适合 2–3 组 |
| columns | column（2–3 条） | 无 | 对照分栏；每栏一组标题与正文 |
| table | row（至少两行两列） | 无 | 首行为统一色表头；列宽平均，建议不超过 5 列 |
| kv | kv | 无 | 左侧名称＋右侧解释，适合定义或条件清单 |
| chain | step | 无 | 竖向编号步骤；适合顺序阅读 |
| flow | step | 无 | 横向步骤与箭头；每行最多 4 步，超出自动另起一行 |
| diagram | image | body | 主图区＋图注；有 body 时在右侧建立说明区 |
| grid | card | 无 | 两列多行卡片，适合 2–4 个概念；奇数末项保持左对齐 |
| dark | statement | reason | 深色背景，突出强观点与理由；key 仍可使用 |
| summary | num | 无 | 编号总结；未写数字的条目自动编号 |
| closing | title2 | 无 | 两行大字＋副标题；正文尽量短 |
| sources | source | 无 | 自动编号参考来源，建议放课程最后 |
| qa | 无 | body | 标题提出问题，key 点题，body 可列讨论问题 |
| section | 无 | 无 | 深色章节分隔页，可用 subtitle 与 key |

每页所有专用字段都必须适用于当前布局。例如 `statement` 是 dark 的字段，而 `statement` 布局直接用 title 表达主句。误用会报出页码和字段名。

## 分组与表格示例

```text
[05]
layout	blocks
title	阅读材料的两个层次
head	材料呈现的内容
body	先用中性语言描述。
head	我们形成的解释
body	交代推断依赖哪些证据。
time	90

[06]
layout	columns
title	区分信息性质
column	观察|材料中明确呈现的内容。
column	推断|基于材料形成的解释。
column	未知|尚缺证据的问题。
time	90

[07]
layout	table
title	比较两个来源
row	维度|来源一|来源二
row	作者|填写作者|填写作者
row	材料范围|填写范围|填写范围
time	90
```

## 流程、卡片与深色页示例

```text
[08]
layout	flow
title	从问题到结论
step	提出问题
step	查找来源
step	比较证据
step	保留未知
time	90

[09]
layout	grid
title	两个阅读提醒
card	核查来源|熟悉感不能替代证据。
card	保留边界|资料没有回答的内容不要补成事实。
time	90

[10]
layout	dark
title	一个需要记住的原则
statement	结论的强度应与证据相匹配。
reason	表达不确定性时，说明具体缺少哪些信息。
reason	不要把猜测包装成已证实的引语。
time	90
```

以上代码块展示独立片段，不是可直接构建的整门课程；正式 deck 必须从 01 开始，逐页配讲稿并满足总时长。完整可运行例子在 `courses/CQB/`，覆盖表内全部布局。

## 容量与换行

中文按字符估算宽度和贪心断行，不按空格切词。引擎为每个文本框计算可用高度，必要时逐步缩小字号，低于最小字号仍放不下则给出页面和 text 字段错误，请拆页。不能把无限长内容挤入固定页面。

侧图保持原比例，剩余空间交给正文。图片区、图注与文字框彼此分离；封面图片与文字是有意叠放，背景不参与内容框重叠检查。

主题中的 `TYPE_SCALE` 决定默认字号，`GEOMETRY` 决定画布、外边距与内容区域。当前版式针对 16:9 设计，修改画布比例需要同时复核各版式；通常只调整颜色、字体和少量字号即可。
