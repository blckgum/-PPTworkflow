# 内容格式完整参考

## 通用规则

- UTF-8 纯文本，允许 UTF-8 BOM；每行一个 `key<TAB>value`，只按第一个实际制表符分隔。
- 值内部可以包含连续空格。首尾空白被去掉；空值请直接省略该可选行。
- 空行和以 `#` 开头的行忽略；不支持行尾注释。
- 未知字段、重复单值字段、错误分页、布局不支持的字段均报错，不会静默忽略。
- 每张幻灯片 `[NN]` 后直到下一分页标记为一个内容块；NN 是从 01 连续递增的两位数字。
- 课程只保存文本、讲稿、图片。禁止把正文写进引擎源码。

## course.txt

| 字段 | 必需 | 默认 / 说明 |
|---|---|---|
| title | 是 | 课程标题、文档属性及输出文件名 |
| org | 是 | 页眉机构名 |
| time_target_min | 是 | 最小分钟数，有限正数 |
| time_target_max | 是 | 最大分钟数，不小于最小值 |
| subtitle | 否 | 空字符串；课程副标题元数据，页面副标题独立填写 |
| docid | 否 | 课程目录名；页眉文档号 |
| deckname | 否 | 课程目录名；保留为课程标识元数据 |
| theme | 否 | military_light，必须是 THEMES 中存在的名称 |

course.txt 所有字段都不可重复。课程名用于定位目录，title 用于命名产物，二者可以不同。

## deck.txt：共用字段

| 字段 | 可重复 | 说明 |
|---|---|---|
| layout | 否 | 必填；布局名称，见布局参考 |
| title | 否 | 必填；本页标题 |
| subtitle | 否 | 本页副标题 |
| key | 否 | 核心句；普通内容页使用统一高亮框 |
| footer | 否 | 页脚来源说明 |
| time | 否 | 正整数秒，默认 90；合计必须满足课程时长范围 |
| note | 否 | 显示在页面底部的主讲提示；完整讲稿另写 notes |
| image | 是 | 素材目录下的图片相对文件名 |
| caption | 是 | 与 image 按出现次序一一对应的图注 |
| image2 | 是 | 附加图片组，排在 image 组后 |
| caption2 | 是 | 与 image2 按出现次序对应 |

`image` 和 `image2` 都能重复；图注可以少于图片，不能多于图片。封面必须且只能有一张 `image`。普通布局将所有侧图自上而下排列，最多三张；diagram 在图片区顺序排列。图少时不会留下多余图片空位。

图片路径支持 `子目录/图片.png`，不能使用绝对路径、`../` 越界路径或通过符号链接逃出素材目录。素材以 RGB PNG 缓存后嵌入，保留图片比例；封面额外裁切并烘入压暗渐变。

## deck.txt：布局专用字段

| 字段 | 可重复 | 格式与说明 | 使用布局 |
|---|---|---|---|
| subtitle2 | 否 | 第二副标题 | cover |
| question | 否 | 开场问题 | cover |
| bullet | 是 | 一行一个要点 | points |
| body | 是 | 一行一段正文 | points、blocks、diagram、qa |
| head | 是 | 与紧随其后的 body 配成一组 | blocks |
| column | 是 | 标题\|正文，按第一个竖线分隔；2–3 条 | columns |
| row | 是 | 各列用竖线分隔，第一行是表头 | table |
| kv | 是 | 名称=内容，按第一个等号分隔 | kv |
| step | 是 | 流程步骤，按文件中的先后顺序 | chain、flow |
| card | 是 | 标题\|正文，按第一个竖线分隔 | grid |
| statement | 否 | 主要强观点 | dark |
| reason | 是 | 支撑观点的理由 | dark |
| num | 是 | 编号加空格加文字，或纯文字自动编号 | summary |
| title2 | 否 | 第二行大标题 | closing |
| source | 是 | 一项参考来源 | sources |

不同布局有各自必填项与字段边界。table 至少两行两列，所有行列数相同；blocks 必须按 `head/body/head/body` 顺序配对。字段值中要使用竖线时，column/card 的正文可包含额外竖线；table 的每个竖线始终代表新列。

## notes/NN.txt

每页必须有对应非空讲稿。按 UTF-8 读取，操作系统换行规范化为 `\n`，其余文本含空行原样保留。

- `【…】` 开头的行在 Word 中加粗。
- `〔…〕` 开头的行在 Word 中使用强调色。
- 其他行均为正文。
- 相同原文进入 PPT 演讲者备注；PPT 页面上的 note 字段不是替代品。

Word 正文从生成 PPT 中带有内容标记的文本框和表格反读，包括图片说明和页面主讲提示；机构、页码、时长等重复装饰不混入正文。Word 采用逐页书签和显式分页，由 V6 对正文、讲稿与分页单元逐项比对。

## 产物与路径

`courses/<目录>/输出/<title>.pptx` 与 `<title> 讲稿.docx`。标题中的 `<>:"/\|?*` 等 Windows 不允许字符被替换成下划线；文件主体最多 70 字符。课程目录名请保持简短，深路径在 Windows 上可考虑 `git config core.longpaths true`。

## 自动校验

| 编号 | 实现 |
|---|---|
| V1 | 比较 PPT 页数与内容块数 |
| V2 | 全部 time 合计，按分钟范围校验；失败输出实际时长 |
| V3 | 原始讲稿非空，且成品 PPT 备注与原文逐字一致 |
| V4 | 所有形状的实际坐标与大小不超出页面，0.01 英寸容差 |
| V5 | 第一页为 cover，有全页图片；源图及嵌入图均至少 2.07 MP |
| V6 | Word 分页单元与 PPT 一致；逐项比较反读正文和原始讲稿 |
| V7 | 导入前编译并词法检查全部引擎源码；中文运行时正文字符串不允许直接写入，错误含路径和行号 |
| V8 | 所有图片路径存在、位于素材目录且能解码；小侧图警告 |
| V9 | 中文逐字符估算文字高度，超过框高一行以上警告；生成时放不下直接报错 |
| V10 | 检测「某人说过」类措辞，警告人工核查；不能替代事实审查 |
| T4 | 排除有意叠放的装饰和背景后，检测内容框重叠；超过五个 bullet 警告 |

V1–V8 的失败与构建失败都会导致非零退出状态；警告单独显示。`--check` 不会自动修复或重新生成任何文件。Word 的实际物理页数还会受字体与排版软件影响，完整 T4 使用 LibreOffice 转 PDF 再确认每页内容、页数和页面坐标。
