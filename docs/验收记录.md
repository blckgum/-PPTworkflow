## 安装与示例

新建独立虚拟环境，再从包源安装 `requirements.txt`，没有复用系统预装的 Python 包：

```bash
python3 -m venv /workspace/.venvs/deckflow
/workspace/.venvs/deckflow/bin/python -m pip install -r requirements.txt
/workspace/.venvs/deckflow/bin/python run.py CQB
```

环境：Python 3.12.14、python-pptx 1.0.2、python-docx 1.2.0、Pillow 12.3.0、lxml 6.1.3。渲染使用环境现成 LibreOfficeDev 26.8 和 Poppler 26.05，中文字体为 Noto Sans CJK SC。

示例构建：17 页，覆盖全部布局，25 分 30 秒；三张原创图片、17 份逐页讲稿。封面 2880×1620，约 4.67 MP。V1–V10 与内容框重叠检查全部通过，没有警告。

单元与成品回归测试：

```bash
/workspace/.venvs/deckflow/bin/python -m unittest discover -s tests -v
```

**21 项全部通过，无跳过。** 包含严格字段、顺序分页、分栏与表格结构、中文换行、错误时长、缺素材、空讲稿、源码卫生、PPT 越界与溢出、Word 正文篡改及 PPT 备注篡改检测。
